# Sofa Browser for Tizen 3

A remote-friendly TizenBrew browser with an on-screen keyboard, pointer controls, bookmarks, best-effort ad filtering and AVPlay support. Target device: Samsung UN55MU630D.

Add this repository using TizenBrew’s Add GitHub Module option. Enter the GitHub owner/repository name.

The package uses TizenBrew’s existing loopback launcher and reinjection into web pages. Hold OK or press Back to open the browser menu.

This initial build passed desktop fixture tests and ES5 syntax checks. Physical TV and live-site playback are not yet verified. Tizen 3’s old browser engine cannot run every modern streaming site; ad filtering is best-effort.

Default shortcuts: https://aether.ist/ and https://v2.streameast.ga/.
